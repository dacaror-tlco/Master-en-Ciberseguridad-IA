# Proxys e interceptación

## Burp Suite
[:material-open-in-new: Sitio oficial](https://portswigger.net/burp)

**Qué hace.** Proxy de interceptación web: inspecciona, modifica y repite peticiones (Repeater, Intruder).

**Cuándo se usa.** Trabajo manual sobre una aplicación web: probar inyecciones, lógica y autenticación.

**Aparece en.** [Sesion 25 Evolve](../otros/general/sesion-25-evolve.md), [IA hibrida, agentes y SQL Injection](../otros/ia/ia-hibrida-agentes-y-sql-injection.md), [IA Practica 1 Grafos Subagentes Infraestructura](../otros/ia/ia-practica-1-grafos-subagentes-infraestructura.md), [Report (2026-09-21)](../otros/informes/report-2026-09-21.md), [Report](../otros/informes/report.md), [Sesion 23 Explotacion Servicios Vulnerables II](../red-team/explotacion/sesion-23-explotacion-servicios-vulnerables-ii.md), [Auditoria WordPress Academy](../red-team/maquinas/auditoria-wordpress-academy.md), [CMS y Curling](../red-team/maquinas/cms-y-curling.md), [Facultad](../red-team/maquinas/facultad.md), [HTB Tier 2](../red-team/maquinas/htb-tier-2.md) (+34)

## FoxyProxy
[:material-open-in-new: Sitio oficial](https://addons.mozilla.org/firefox/addon/foxyproxy-standard/)

**Qué hace.** Extensión de navegador para cambiar de proxy con un clic.

**Cuándo se usa.** Enrutar el tráfico del navegador hacia Burp y volver a la normalidad rápido.
