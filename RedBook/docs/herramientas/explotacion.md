# Explotación

## Exploit-DB
[:material-open-in-new: Sitio oficial](https://www.exploit-db.com/)

**Qué hace.** Base de datos pública de exploits y PoCs.

**Cuándo se usa.** Consultar y descargar exploits para vulnerabilidades conocidas.

**Aparece en.** [Glosario Ciberseguridad](../otros/general/glosario-ciberseguridad.md), [Facultad](../red-team/maquinas/facultad.md), [Nibbles - Apuntes](../red-team/maquinas/nibbles-apuntes.md), [Sesion 26 Mr. Robot II Evolve](../red-team/maquinas/sesion-26-mr-robot-ii-evolve.md), [OSINT Superficie](../red-team/osint/osint-superficie.md), [CMS](../red-team/web/cms.md)

## Metasploit
[:material-open-in-new: Sitio oficial](https://www.metasploit.com/)

**Qué hace.** Framework de explotación: módulos de exploits, payloads y post-explotación.

**Cuándo se usa.** Explotar servicios con exploit conocido y generar payloads (msfvenom).

**Aparece en.** [Sesion 25 Evolve](../otros/general/sesion-25-evolve.md), [Explotacion Maquinas Locales I](../red-team/explotacion/explotacion-maquinas-locales-i.md), [Explotacion Servicios III](../red-team/explotacion/explotacion-servicios-iii.md), [Sesion 23 Explotacion Servicios Vulnerables II](../red-team/explotacion/sesion-23-explotacion-servicios-vulnerables-ii.md), [HTB Starting Point Tier 0](../red-team/maquinas/htb-starting-point-tier-0.md), [HTB Starting Point Tier 1](../red-team/maquinas/htb-starting-point-tier-1.md), [HTB Tier 2](../red-team/maquinas/htb-tier-2.md), [Nibbles - Apuntes](../red-team/maquinas/nibbles-apuntes.md), [Repaso semanal VII - Devel](../red-team/maquinas/repaso-semanal-vii-devel.md), [Sesion 26 Mr. Robot II Evolve](../red-team/maquinas/sesion-26-mr-robot-ii-evolve.md) (+4)

## searchsploit
[:material-open-in-new: Sitio oficial](https://gitlab.com/exploit-database/exploitdb)

**Qué hace.** Buscador local de Exploit-DB desde la terminal.

**Cuándo se usa.** Buscar exploits públicos para la versión concreta de un servicio.

**Aparece en.** [OWASP CVSS CWE CVE](../metodologias/estandares/owasp-cvss-cwe-cve.md), [Glosario Ciberseguridad](../otros/general/glosario-ciberseguridad.md), [Sesion 25 Evolve](../otros/general/sesion-25-evolve.md), [Facultad](../red-team/maquinas/facultad.md), [HTB Starting Point Tier 0](../red-team/maquinas/htb-starting-point-tier-0.md), [Nibbles - Apuntes](../red-team/maquinas/nibbles-apuntes.md), [Practica 1 Webos Castillo Gomez](../red-team/maquinas/practica-1-webos-castillo-gomez.md), [File Upload Bounty](../red-team/web/file-upload-bounty.md)

## sqlmap
[:material-open-in-new: Sitio oficial](https://sqlmap.org/)

**Qué hace.** Automatiza la detección y explotación de inyección SQL.

**Cuándo se usa.** Tras confirmar (o sospechar) SQLi, para extraer datos y enumerar la base de datos.

**Aparece en.** [Sesión 2026-09-17](../otros/general/apuntes-17-09-2026-carlos-castillo.md), [Report (2026-09-21)](../otros/informes/report-2026-09-21.md), [HTB Tier 2](../red-team/maquinas/htb-tier-2.md), [Repaso Semanal Vaccine Oopsie](../red-team/maquinas/repaso-semanal-vaccine-oopsie.md), [Repaso semanal VII - Devel](../red-team/maquinas/repaso-semanal-vii-devel.md), [SSTI y evidencias web - GoodGames](../red-team/maquinas/ssti-y-evidencias-web-goodgames.md), [Vaccine Repaso](../red-team/maquinas/vaccine-repaso.md), [Vaccine](../red-team/maquinas/vaccine.md), [Sesion 29 OWASP Web Burp](../red-team/web/sesion-29-owasp-web-burp.md), [SQL despliegue seguro y consultas](../red-team/web/sql-despliegue-seguro-y-consultas.md) (+5)
