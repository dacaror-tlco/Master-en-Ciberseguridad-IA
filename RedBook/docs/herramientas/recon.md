# Reconocimiento y OSINT

## Amass
[:material-open-in-new: Sitio oficial](https://github.com/owasp-amass/amass)

**Qué hace.** Mapeo de superficie de ataque y enumeración de subdominios (OWASP).

**Cuándo se usa.** Reconocimiento de dominios amplio, combinando fuentes pasivas y activas.

**Aparece en.** [OSINT Superficie](../red-team/osint/osint-superficie.md)

## dig
[:material-open-in-new: Sitio oficial](https://linux.die.net/man/1/dig)

**Qué hace.** Cliente DNS para consultar registros (A, MX, TXT, NS, transferencias de zona).

**Cuándo se usa.** Reconocimiento DNS de un dominio y búsqueda de subdominios o fugas de información.

**Aparece en.** [Intro Redes](../otros/fundamentos/intro-redes.md), [OSINT Superficie](../red-team/osint/osint-superficie.md)

## nslookup
[:material-open-in-new: Sitio oficial](https://linux.die.net/man/1/nslookup)

**Qué hace.** Cliente DNS interactivo multiplataforma, alternativa básica a dig.

**Cuándo se usa.** Resolver nombres y comprobar registros DNS rápidamente, también en Windows.

**Aparece en.** [Intro Redes](../otros/fundamentos/intro-redes.md)

## Sublist3r
[:material-open-in-new: Sitio oficial](https://github.com/aboul3la/Sublist3r)

**Qué hace.** Enumera subdominios usando buscadores y fuentes públicas.

**Cuándo se usa.** Descubrir subdominios de un objetivo en reconocimiento pasivo.

**Aparece en.** [Glosario Ciberseguridad](../otros/general/glosario-ciberseguridad.md)

## theHarvester
[:material-open-in-new: Sitio oficial](https://github.com/laramies/theHarvester)

**Qué hace.** Recopila correos, subdominios, hosts y nombres a partir de fuentes públicas.

**Cuándo se usa.** Fase OSINT: dibujar la superficie expuesta de una organización sin tocarla.
