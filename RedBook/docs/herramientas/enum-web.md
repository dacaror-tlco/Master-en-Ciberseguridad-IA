# Enumeración web y fuzzing

## CeWL
[:material-open-in-new: Sitio oficial](https://github.com/digininja/CeWL)

**Qué hace.** Genera diccionarios a partir de las palabras de un sitio web.

**Cuándo se usa.** Crear wordlists a medida del objetivo para fuzzing o ataque de credenciales.

## dirb
[:material-open-in-new: Sitio oficial](https://www.kali.org/tools/dirb/)

**Qué hace.** Escáner clásico de contenido web por diccionario.

**Cuándo se usa.** Enumeración de directorios básica cuando no hay nada más a mano.

**Aparece en.** [Explotacion Servicios III](../red-team/explotacion/explotacion-servicios-iii.md), [Sesion 23 Explotacion Servicios Vulnerables II](../red-team/explotacion/sesion-23-explotacion-servicios-vulnerables-ii.md), [HTB Tier 1 Responder Three](../red-team/maquinas/htb-tier-1-responder-three.md), [Rockstar Escalada Linux LFI](../red-team/maquinas/rockstar-escalada-linux-lfi.md), [Sesion 27 XXE LFI Nike](../red-team/maquinas/sesion-27-xxe-lfi-nike.md), [Anonimato Ingenieria Social Rockstar](../red-team/osint/anonimato-ingenieria-social-rockstar.md), [Fuzzing Parametros x 8](../red-team/web/fuzzing-parametros-x-8.md), [Repaso Enumeracion Web](../red-team/web/repaso-enumeracion-web.md)

## dirsearch
[:material-open-in-new: Sitio oficial](https://github.com/maurosoria/dirsearch)

**Qué hace.** Fuerza bruta de rutas y ficheros web con diccionarios.

**Cuándo se usa.** Descubrir paneles, backups y endpoints ocultos en un sitio.

**Aparece en.** [Sesión 2026-09-17](../otros/general/apuntes-17-09-2026-carlos-castillo.md), [Report (2026-09-21)](../otros/informes/report-2026-09-21.md), [Explotacion Maquinas Locales I](../red-team/explotacion/explotacion-maquinas-locales-i.md), [Auditoria WordPress Academy](../red-team/maquinas/auditoria-wordpress-academy.md), [Facultad](../red-team/maquinas/facultad.md), [Magic](../red-team/maquinas/magic.md), [Nibbles - Apuntes](../red-team/maquinas/nibbles-apuntes.md), [Nibbles HTB](../red-team/maquinas/nibbles-htb.md), [Practica 1 Webos Castillo Gomez](../red-team/maquinas/practica-1-webos-castillo-gomez.md), [Repaso Metodologia Web SSTI CasaPaco](../red-team/maquinas/repaso-metodologia-web-ssti-casapaco.md) (+19)

## feroxbuster
[:material-open-in-new: Sitio oficial](https://github.com/epi052/feroxbuster)

**Qué hace.** Descubridor de contenido web recursivo y rápido.

**Cuándo se usa.** Enumeración de directorios con recursión automática sobre lo que va encontrando.

**Aparece en.** [IA hibrida, agentes y SQL Injection](../otros/ia/ia-hibrida-agentes-y-sql-injection.md), [Explotacion Maquinas Locales I](../red-team/explotacion/explotacion-maquinas-locales-i.md), [Explotacion Servicios III](../red-team/explotacion/explotacion-servicios-iii.md), [Auditoria WordPress Academy](../red-team/maquinas/auditoria-wordpress-academy.md), [HTB Tier 2](../red-team/maquinas/htb-tier-2.md), [Repaso Semanal Vaccine Oopsie](../red-team/maquinas/repaso-semanal-vaccine-oopsie.md), [Rockstar Escalada Linux LFI](../red-team/maquinas/rockstar-escalada-linux-lfi.md), [Sesion 27 XXE LFI Nike](../red-team/maquinas/sesion-27-xxe-lfi-nike.md), [Son ROBOTS](../red-team/maquinas/son-robots.md), [SSTI y evidencias web - GoodGames](../red-team/maquinas/ssti-y-evidencias-web-goodgames.md) (+10)

## ffuf
[:material-open-in-new: Sitio oficial](https://github.com/ffuf/ffuf)

**Qué hace.** Fuzzer web rápido para directorios, ficheros, parámetros y subdominios.

**Cuándo se usa.** Descubrir contenido oculto y parámetros cuando necesitas velocidad y filtros finos.

**Aparece en.** [Glosario Ciberseguridad](../otros/general/glosario-ciberseguridad.md), [IA Practica 1 Grafos Subagentes Infraestructura](../otros/ia/ia-practica-1-grafos-subagentes-infraestructura.md), [Explotacion Maquinas Locales I](../red-team/explotacion/explotacion-maquinas-locales-i.md), [Explotacion Servicios III](../red-team/explotacion/explotacion-servicios-iii.md), [Sesion 23 Explotacion Servicios Vulnerables II](../red-team/explotacion/sesion-23-explotacion-servicios-vulnerables-ii.md), [Auditoria WordPress Academy](../red-team/maquinas/auditoria-wordpress-academy.md), [HTB Starting Point Tier 1](../red-team/maquinas/htb-starting-point-tier-1.md), [HTB Tier 1 Responder Three](../red-team/maquinas/htb-tier-1-responder-three.md), [HTB Tier 2](../red-team/maquinas/htb-tier-2.md), [Nibbles HTB](../red-team/maquinas/nibbles-htb.md) (+12)

## gobuster
[:material-open-in-new: Sitio oficial](https://github.com/OJ/gobuster)

**Qué hace.** Fuerza bruta de directorios, DNS y vhosts.

**Cuándo se usa.** Enumeración de rutas y subdominios como alternativa sencilla a ffuf.

**Aparece en.** [Report](../otros/informes/report.md), [Explotacion Maquinas Locales I](../red-team/explotacion/explotacion-maquinas-locales-i.md), [Auditoria WordPress Academy](../red-team/maquinas/auditoria-wordpress-academy.md), [HTB Tier 1 Responder Three](../red-team/maquinas/htb-tier-1-responder-three.md), [Nibbles HTB](../red-team/maquinas/nibbles-htb.md), [Repaso Semanal Vaccine Oopsie](../red-team/maquinas/repaso-semanal-vaccine-oopsie.md), [Rockstar Escalada Linux LFI](../red-team/maquinas/rockstar-escalada-linux-lfi.md), [Sesion 26 Mr. Robot II Evolve](../red-team/maquinas/sesion-26-mr-robot-ii-evolve.md), [Sesion 27 XXE LFI Nike](../red-team/maquinas/sesion-27-xxe-lfi-nike.md), [Anonimato Ingenieria Social Rockstar](../red-team/osint/anonimato-ingenieria-social-rockstar.md) (+8)

## Nikto
[:material-open-in-new: Sitio oficial](https://github.com/sullo/nikto)

**Cuándo se usa.** Barrido inicial de un servidor web para detectar problemas evidentes.

## SecLists
[:material-open-in-new: Sitio oficial](https://github.com/danielmiessler/SecLists)

**Qué hace.** Colección de diccionarios (rutas, usuarios, contraseñas, payloads).

**Cuándo se usa.** Fuente de wordlists para fuzzing, fuerza bruta y pruebas de inyección.

**Aparece en.** [Glosario Ciberseguridad](../otros/general/glosario-ciberseguridad.md), [Explotacion Servicios III](../red-team/explotacion/explotacion-servicios-iii.md), [Sesion 23 Explotacion Servicios Vulnerables II](../red-team/explotacion/sesion-23-explotacion-servicios-vulnerables-ii.md), [Auditoria WordPress Academy](../red-team/maquinas/auditoria-wordpress-academy.md), [Facultad](../red-team/maquinas/facultad.md), [HTB Starting Point Tier 1](../red-team/maquinas/htb-starting-point-tier-1.md), [HTB Tier 1 Responder Three](../red-team/maquinas/htb-tier-1-responder-three.md), [Practica 1 Webos Castillo Gomez](../red-team/maquinas/practica-1-webos-castillo-gomez.md), [Repaso Metodologia Web SSTI CasaPaco](../red-team/maquinas/repaso-metodologia-web-ssti-casapaco.md), [Repaso Semanal Vaccine Oopsie](../red-team/maquinas/repaso-semanal-vaccine-oopsie.md) (+6)
