# **① El mercado actual: la realidad**

El sector de ciberseguridad tiene mucha demanda pero también **alta competencia**. Un reclutador toma la decisión en los primeros 6 segundos de ver tu perfil. Lo que importa: diferenciación.

| **⚠ REALIDAD** | Todo el mundo puede programar, todo el mundo usa datos. La competencia ha subido mucho. Para perfiles tech: lo que diferencia es evidencia real de habilidades, no el CV. |
| --- | --- |

| **Elemento** | **Impacto en selección** |
| --- | --- |
| CV + LinkedIn | Mínimo indispensable. Si solo tienes esto, eres uno más. |
| Portafolio técnico | Te coloca automáticamente en el top de candidatos. |
| CTFs y certificaciones | Demuestra habilidad práctica verificable. |
| Contribuciones Open Source | Código real, visible, verificable. |
| Artículos técnicos | Visibilidad y demostración de conocimiento. |

# **② Portafolio técnico: el diferenciador clave**

La grandísima mayoría de candidatos se queda en el mínimo (CV + LinkedIn). Un portafolio técnico real **automáticamente te pone en el top**.

## **GitHub como portafolio**

| # Un buen perfil de GitHub para ciberseguridad incluye:  # 1. README.md del perfil (especial: usuario/usuario repo)  # → Preséntate, tus especialidades, tus contactos  # 2. Writeups de CTF:  # → CTF-NombreEvento-2024/  # ├── README.md (solución explicada)  # ├── exploit.py  # └── screenshots/  # 3. Herramientas propias:  # → Scanner básico, automatización de tareas  # → Con README claro: qué hace, cómo se usa  # 4. Laboratorios documentados:  # → HackTheBox, TryHackMe writeups  # → Documentación de tu home lab  # 5. Commits regulares:  # → La gráfica de actividad es visible  # → Aunque sean pequeñas mejoras, demuestra constancia |
| --- |

| **💡 ESTRUCTURA** | Los reclutadores no leen el código. Leen el README. Cada repositorio debe tener un README claro: qué es, para qué sirve, cómo se usa, captura de pantalla. |
| --- | --- |

# **③ LinkedIn: optimización del perfil**

| **Sección** | **Recomendación** |
| --- | --- |
| Foto profesional | No obligatoria pero aumenta visibilidad. Fondo neutro. |
| Titular (headline) | No pongas solo el título. Describe qué haces y en qué te especializas. |
| About/Acerca de | 3-5 líneas. Quién eres, qué haces, qué buscas. |
| Experiencia | Describe logros, no solo responsabilidades. Métricas si es posible. |
| Certificaciones | Añade todas: eJPT, CompTIA Security+, OSCP... |
| Habilidades | Mínimo 50. Las primeras 3 son las más importantes. |
| Publicaciones | Un post técnico al mes genera mucha visibilidad. |

| # Ejemplos de titulares efectivos vs inefectivos:  # ❌ Malo:  "Estudiante de ciberseguridad"  "Buscando trabajo en IT"  # ✅ Bueno:  "Pentester en formación | eJPT | CTF player | HackTheBox Top 10%"  "Ciberseguridad ofensiva | Bug Bounty | Python | Kali Linux"  "SOC Analyst | Blue Team | SIEM | Threat Detection" |
| --- |

# **④ CTFs: la forma más rápida de demostrar habilidad**

Los Capture The Flag son competiciones de hacking ético donde se resuelven retos técnicos. Son **verificables, documentables y muy valorados por reclutadores**

| **Plataforma** | **Descripción** |
| --- | --- |
| HackTheBox (HTB) | La más reconocida. Tiene ranking visible. Muy valorada en entrevistas. |
| TryHackMe | Más guiada, ideal para empezar. Con rutas de aprendizaje. |
| CTFtime.org | Calendario de competiciones CTF a nivel mundial. |
| PicoCTF | Orientada a estudiantes. Buena para empezar. |
| VulnHub | VMs descargables para practicar sin conexión. |
| PortSwigger Web Academy | La mejor para aprender y practicar hacking web. |

| **💡 WRITEUPS** | Resolver un CTF y documentar el proceso (writeup) demuestra mucho más que solo resolver el reto. Publicar writeups en un blog o GitHub → visibilidad + portafolio. |
| --- | --- |

# **⑤ Certificaciones relevantes**

| **Certificación** | **Descripción** |
| --- | --- |
| eJPT (eLearnSecurity) | Junior Penetration Tester. Primera cert ofensiva práctica. Muy accesible. |
| CompTIA Security+ | Base de conocimiento amplia. Reconocida en empresas grandes. |
| CompTIA PenTest+ | Nivel intermedio ofensivo. |
| eCPPT (eLearnSecurity) | Penetration Tester Professional. Siguiente paso al eJPT. |
| OSCP (Offensive Security) | El estándar de oro del pentesting. Muy difícil, muy valorada. |
| CEH (EC-Council) | Reconocida en grandes corporaciones y AAPP. Más teórica. |
| PNPT (TCM Security) | Práctica, asequible, muy valorada en la comunidad. |

| **🎯 RUTA RECOMENDADA** | eJPT → PNPT o eCPPT → OSCP. El eJPT es el objetivo inmediato del máster. La OSCP es el objetivo a 1-2 años. |

# **⑥ El proceso de selección en ciberseguridad**

| **CV/LinkedIn filtra** | -> | **Prueba técnica / CTF** | -> | **Entrevista técnica** | -> | **Entrevista cultural** | -> | **Oferta** |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |

| **Fase** | **Qué evalúan** |
| --- | --- |
| Prueba técnica | CTF corto, análisis de vulnerabilidades, ejercicio de código. Práctico. |
| Entrevista técnica | Preguntas sobre herramientas, metodologías, CVEs conocidos, laboratorios. |
| Entrevista cultural | Soft skills, trabajo en equipo, comunicación con clientes. |
| Negociación | Conoce tu valor. Investiga salarios del sector antes. |

| **💡 PREPARACIÓN** | Para entrevistas técnicas: estudia el OWASP Top 10, practica explicar vulnerabilidades (XSS, SQLi, LFI...) en voz alta, y ten 2-3 laboratorios de HackTheBox que puedas explicar en detalle. |
| --- | --- |

# **⑦ Personal branding y visibilidad**

La visibilidad en la comunidad de ciberseguridad es un multiplicador de oportunidades.

| **Canal** | **Descripción** |
| --- | --- |
| Blog técnico | Medium, Substack, GitHub Pages. Un post al mes sobre algo que hayas aprendido. |
| Twitter/X | Seguir investigadores, compartir writeups, comentar vulnerabilidades nuevas. |
| YouTube / Twitch | Streamings de CTF o tutoriales. Alta visibilidad pero alto esfuerzo. |
| Conferencias | DEF CON, Black Hat, RootedCON, NavajaNegra. Asistir y hacer networking. |
| Comunidades Discord | HackTheBox, TryHackMe, Discord servers del sector. Networking. |
| Bug Bounty | Hackerone, Bugcrowd. CVEs propios tienen muchísimo valor en el CV. |

| **💡 CONSEJO CLAVE** | No tienes que hacer todo a la vez. Elige 1-2 canales y sé consistente. Un blog con 10 artículos técnicos de calidad vale más que 50 posts de relleno. |
| --- | --- |

# **⑧ Momentos clave en el año para buscar trabajo**

| **Momento** | **Observación** |
| --- | --- |
| Enero-Febrero | Presupuestos nuevos. Muchas empresas contratan a principios de año. |
| Septiembre-Octubre | Vuelta de vacaciones. Segundo pico de contratación. |
| Ferias / conferencias | Networking presencial. Entrega tarjeta, conecta en LinkedIn ese mismo día. |
| Evitar | Agosto (vacaciones) y Diciembre (cierre de año). Menor actividad de RRHH. |
