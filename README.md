# Master-en-Ciberseguridad-IA

## 🛠️ Herramientas

| Herramienta | Descripción |
|-------------|-------------|
| [NmapGUI](./nmapgui/) | Interfaz gráfica profesional para nmap — configura escaneos, visualiza resultados por hosts/puertos/servicios/OS y exporta a JSON. Python + PyQt6, dark theme Catppuccin Mocha. |
| [ScamShield](./scam-shield/) | Herramienta de recolección de evidencias y análisis de riesgo de estafas online (dominios, emails, wallets cripto, teléfonos, imágenes...) con capa de IA y monitorización continua. FastAPI + frontend propio. Demo pública: [dfir.gondorhub.com](https://dfir.gondorhub.com) |
| [DFIR-Nexus](./DFIR-Nexus/) | Plataforma modular de apoyo a la investigación forense digital, proyecto principal del máster: casos y evidencias (integridad SHA-256, borrado lógico y auditoría), OSINT, tracking post-incidente, timeline e informes con IA, más asistente conversacional y servidor MCP. ScamShield nació como su primer módulo y hoy es su backend de OSINT. React + FastAPI + MySQL + Docker. Instancia publicada: [nexus.gondorhub.com](https://nexus.gondorhub.com) |
| [RedBook](./RedBook/) | Base de conocimiento del máster (MkDocs Material): metodología por fases, guía por puerto/servicio, walkthroughs, chuletas y catálogo de herramientas generado a partir de los apuntes. Desplegable con Docker en la Raspberry Pi. |
